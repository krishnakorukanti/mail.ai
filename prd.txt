# mail.ai V1: AI-Powered Email Management System - Backend PRD

# Overview
mail.ai V1 backend system provides intelligent email processing and management capabilities, focusing on email classification, spam detection, and context-aware email composition using AI/ML technologies.

## Core Objectives
- Automated email processing and classification
- Intelligent spam detection and cleanup
- Context-aware email composition
- Real-time email notifications
- Secure email data management

## Target Scale for V1
- Up to 10,000 emails per user
- Up to 1,000 active users
- Processing latency < 2 seconds per email
- Real-time notification delivery

# Technical Architecture

## Core Technologies
1. Backend Framework
   - AdonisJS 5.x
   - TypeScript
   - Node.js 18+

2. Databases
   - PostgreSQL 15+ (Primary Database)
     - User data
     - Email metadata
     - Authentication records
     - System configurations
   
   - ChromaDB (Vector Database)
     - Email embeddings
     - Semantic search indexes
     - Context storage for LLM

3. AI/ML Stack
   - LangChain.js
   - OpenAI API (GPT-4)
   - Email classification models
   - Text embeddings

4. Authentication
   - Google OAuth 2.0
   - JWT tokens
   - Session management

5. Message Queue
   - Bull for Redis
   - Email processing queues
   - Notification queues

# Core Features & Implementation

## 1. User Authentication System
### Features
- Google OAuth integration
- JWT-based session management
- Secure token storage
- Rate limiting

### Data Model: User
The user model stores essential information including:
- Unique identifier and email
- Google OAuth credentials (ID and tokens)
- Email synchronization status tracking
- Last sync timestamp
- User preferences and settings
- Token refresh mechanism
- Security and rate limiting data

## 2. Email Processing System
### Initial Inbox Processing
- Batch processing of existing emails
- Classification and flagging
- Spam detection and removal
- Vector embedding generation

### Data Models
#### Email Processing Record
Tracks the processing status of each email with:
- Processing status tracking
- Classification results
- Spam score calculation
- Importance level assignment
- Vector embeddings storage
- Processing metadata and timestamps

#### Email Classification
Stores classification results including:
- Category assignment
- Confidence scoring
- Multiple flag assignments
- Spam detection results
- Promotional content detection
- Sentiment analysis results

## 3. Real-time Email Processing
### Features
- Webhook integration with Gmail
- Real-time email classification
- Instant notification dispatch
- Context updating

### Queue Configuration
The email processing queue system includes:
- Unique queue identification
- User and email tracking
- Priority-based processing
- Timestamp tracking
- Retry mechanism with exponential backoff
- Error handling and logging
- Queue monitoring and metrics

## 4. Context-Aware Email Composer
### Features
- Previous email context retrieval
- Semantic search in email history
- Smart suggestions
- Draft management

### Data Model: Email Context
Manages email context with:
- Thread identification
- Historical email storage
- Relevant context mapping
- Similarity scoring
- Content storage
- Smart suggestion storage
- Context retrieval optimization

## 5. Notification Service
### Features
- Real-time email notifications
- Priority-based delivery
- Delivery status tracking
- User preference management

### Data Model: Notification
Handles notification management with:
- Unique notification tracking
- User association
- Email reference
- Type classification
- Priority assignment
- Status tracking
- Metadata storage
- Delivery confirmation
