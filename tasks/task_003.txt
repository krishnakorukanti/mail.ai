## 1. Configure Google OAuth Provider and User Model [pending]
### Dependencies: None
### Description: Set up the Google OAuth 2.0 provider configuration, create the necessary user model with OAuth credential storage, and implement the authentication controller for handling login flows.
### Details:
1. Install required packages: `npm i @adonisjs/auth @adonisjs/ally` etc
2. Register a new project in Google Cloud Platform:
   - Navigate to API & Services > Credentials
   - Create OAuth 2.0 Client ID
   - Configure Authorized Redirect URIs (e.g., `http://localhost:3333/auth/google/callback` for development)
   - Save Client ID and Client Secret as environment variables
3. Configure Google OAuth provider in `config/auth.ts`:
   - Set up passport strategy with Google provider
   - Define scopes (recommend: ['profile', 'email'])
   - Configure callback URL
4. Create or modify User model to store OAuth credentials:
   - Add fields: `email`, `googleId`, `name`, `avatar`, `refreshToken`
   - Create migration for the users table
   - Add methods for finding users by OAuth ID
5. Create AuthController with login method:
   - Implement Google OAuth authentication flow
   - Handle user creation/retrieval based on Google profile
   - Use state parameter to prevent CSRF attacks
6. Testing approach:
   - Unit test User model methods
   - Mock Google OAuth responses for controller tests
   - Test user creation and retrieval flows

## 2. Implement JWT Token Management System [pending]
### Dependencies: 3.1
### Description: Build a comprehensive JWT token management system including token generation, validation, and refresh mechanisms to handle user authentication securely.
### Details:
1. Create a JWT service for token operations:
   - Implement token generation with appropriate claims (userId, email)
   - Set short-lived access tokens (15 minutes) and longer refresh tokens (7 days)
   - Add token validation and payload extraction functions
   - Use environment variables for JWT secret keys
2. Extend AuthController with additional methods:
   - Complete the login flow to generate and return JWT tokens
   - Implement refresh token endpoint to issue new access tokens
   - Create logout method to invalidate tokens
3. Create a token blacklist mechanism:
   - Use Redis or database to store revoked tokens
   - Implement token rotation for refresh tokens
   - Add checks during validation to verify tokens aren't blacklisted
4. Implement secure token storage:
   - Configure HTTP-only, secure cookies for tokens
   - Add appropriate expiration and path settings
   - Implement CSRF protection for token endpoints
5. Testing approach:
   - Unit test JWT service methods
   - Test token generation, validation, and refresh flows
   - Verify token expiration and blacklisting works correctly
