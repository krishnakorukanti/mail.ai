### Dependencies: 6.1
### Description: Create the processor functions for each queue type with robust error handling, retry logic, dead-letter queues, and priority-based processing.
### Details:
1. Create a processor directory structure to organize different queue processors
2. Implement the email processor with:
   - Exponential backoff retry logic (starting with 5s, then 10s, 20s, etc.)
   - Proper error classification (retriable vs. non-retriable errors)

   - Concurrency limits (process 5 emails at a time)
3. Implement notification processor with similar patterns but adjusted for notification requirements

5. Implement dead-letter queue logic:
   - After max retries, move failed jobs to DLQ

   - Configure job options with priority levels (high, medium, low)
   - Implement priority queue handlers
7. Create integration tests for each processor
